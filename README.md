# RESTful API Integration & Network Error Handling

This project demonstrates RESTful API integration using http, JSON serialization, pagination, loading states, and error handling.

## Key Features Implemented
* **HTTP Methods:** Executes GET, POST, and PUT operations against external API endpoints.
* **Data Serialization:** Model class (`Post`) with `fromJson()` and `toJson()` mapping methods.
* **Pagination & Refresh:** Native `RefreshIndicator` for pull-to-refresh and infinite scroll pagination listener.
* **Error & Loading UI:** Includes network error banners and skeleton loading placeholders during data fetches.
